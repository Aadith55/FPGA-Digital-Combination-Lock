# Constraints

The project report specifies these ZedBoard mappings:

| Signal | Pin |
|---|---|
| 100 MHz clock | Y9 |
| BTN1 reset | R18 |
| BTN0 enter | T18 |
| SW inputs | F21, H22, G22, F22 |
| Unlock LED | U14 |
| Lockout LED | U19 |

The original XDC source was not provided with the RTL, so this repository does not invent one.

The intended system clock is 100 MHz (10 ns period).
